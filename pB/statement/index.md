# 最小排序

## 題目敘述

給一個大小為 $N$ 的數列，求 「**不排序前面幾個元素** 才會使此數列的**逆序數**小於等於 $X$ 」的最大值

(相當於 $N$ 減掉「要排序後面幾個元素的最小值才會使此數列的**逆序數**小於等於 $X$ 」的最大值) 。

**逆序數的定義:**

在一個陣列中，若有一對索引 $(i, \space j)$ 滿足以下兩個條件：

$i<j$ 且 a[i]>a[j]


## 輸入

$N\ \ X$

$A_1,\ A_2,\ A_3,\ ... ,\ A_N$

## 輸出

**至多要不排序前面幾個元素**的個數

## 輸入限制
- $N \space (1 \le N \le 2\times 10^6)$
- $X \space (0 \le X \le 10^{13})$
- $1 \le A_i \le N (1 \le i \le N)$
