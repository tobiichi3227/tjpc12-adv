## 題目敘述

？哥最近也在打瓦，但因為太菜了，所以常常被打爆，死的不明不白，導致心態非常不穩定。

經過？哥的仔細思考，自己會殺爆的原因就是因為瓦的地圖太複雜了! 一個敵人想從A地點到B地點有好幾種走法，讓？哥每次都摸不清敵人的進攻路徑。

因此他下載了一個「無限冰牆」的外掛，可以針對一條長度為 $L$ 的路徑使用 $L$ 次冰牆技能把路封起來，使敵人無法通過，這樣對於每個點的敵人就只有一種路徑進攻？哥所處的地點!

但是他發現如果任兩點沒有連通的路，或是技能使用的太頻繁的話，很容易就會被發現裝了外掛，因此依舊要保持任兩地點的聯通性，以及使用最少冰牆技能使用次數。

今天瓦的地圖有 $N$ 個地點， $M$ 條路徑，每條路徑都有對應的長度 $L_i$ ，請你幫助？哥求出至少要使用幾次技能才能滿足上述條件。

\clearpage

## 輸入
第一行有兩個數字 $N, \ (1 \le N \le 10^6)$, $M, \ (N-1 \le M \le \frac{N*(N-1)}{2})$ ，代表有$N$個地點以及$M$條路。

接下來有 $M$ 行，每一行有三個數字 $U_i \ (1 \le U_i \le N)$  ,  $V_i \ (1 \le V_i \le N)$  ,  $L_i \ (1 \le L_i \le 10^9), \ (1 \le i \le M)$ ，分別代表第 $i$ 條路的兩端點以及該條路徑之長度。

保證所有點是連通的，且沒有重邊和自環。

## 輸出

？哥最少的技能施放次數。
