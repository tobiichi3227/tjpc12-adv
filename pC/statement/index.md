在這個有許多魔獸(monster)的世界中，每個人一來到這個世界就有一個固定不變的能力值 s ，**不管用什麼辦法、再怎麼鍛鍊都不能上升**，同時我們擁有一個表現值 o ，一開始為能力值的平方($s^2$)，但是透過討伐怪物可以讓你的**表現值**上升，若有一個能力值為k的魔獸被你打倒了，你會獲得 2k 的表現值，每打倒一隻魔獸你的表現值就會立即上升，所以你可以一直打倒魔獸來提高你的表現值，讓**能力值看起來變高 (看起來的能力值=$\sqrt 表現值$)**。今天我們的主角 "DB0917" 擁有一個特殊能力 "闇影提取" 可以連魔獸的靈魂一起取走，因此可以提升獲得的表現值，其提升的倍率會是對戰完的魔獸的能力值的一半，注意，魔獸和你對戰完後，能力值會增加為先前你的**看起來的能力值**的兩倍，就算死了也是一樣，對，魔獸們就是這麼誇張，雖然死了也無濟於事反而還會幫助到你就是了XD，特殊能力當然是伴隨著詛咒而來，這個詛咒是會讓 n 天的魔獸變為兩隻，也就是 DB0917 需要先對付完一隻再對付下一隻(嗯，他們沒有團體攻擊的概念)，雖然看起來非常危險，但因為他是主角，所以就算是多厲害，多多隻的魔獸你在最後都一定會打倒，而且他很幸運的練得控制詛咒發動時間的能力。因此他給自己一個目標，要練到表現值為x，世界也很幫助他，會讓接下來的d天都有魔獸跑過來打他 (他可以選擇打或不打或釋放詛咒)，所以請你幫他計算他最快什麼時候的表現值可以超過x ($\geq$ x)。

\clearpage

## 輸入
第一行會給你四個數 s, d, n, x ， s 代表你的能力值， d 代表接下來會有 d 天的魔獸過來要打你， n 代表接下來的 d 天中會有 n 天魔獸會變兩隻 (當然，你可以控制出現詛咒的日期), x 代表你給自己設定要到達的表現值，第二行有 d 個數字 $k_i$ $(1 \leq i \leq d)$ 代表接下來每天的魔獸的能力值

## 輸出
輸出 DB0917 的表現值最快什麼時候可以超過 x, 如果無論如何都無法超過 x ，請輸出 -1

## 輸入限制
$$0 \leq s \leq 10^9$$
$$1 \leq d \leq 10^6$$
$$0 \leq n \leq d$$
$$0 \leq x \leq 10^{18}$$
$$0 \leq k_i \leq 10^6\ (1 \leq i \leq d)$$
